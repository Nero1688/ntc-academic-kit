# 手動安裝說明

做法只有一個：把 `skills` 資料夾裡的九個子資料夾，複製到你所用工具的「個人技能目錄」。

九個資料夾：kit-guide、topic-scout、lit-search、lit-matrix、writing-coach、paper-selfcheck、grant-writer、ai-disclosure、prompt-coach。

| 工具 | 個人技能目錄（查證日 2026-11-09） |
|---|---|
| Claude Code | `~/.claude/skills`（Windows 為 `C:\Users\你的帳號\.claude\skills`） |
| Codex | `$HOME/.agents/skills`（Windows 為 `C:\Users\你的帳號\.agents\skills`） |

路徑以兩個工具的官方文件為準，若日後改變，請以官方文件為準。如果目標已有同名資料夾，請先把舊的改名（例如加上 `.bak-日期`）再複製，避免覆蓋。

## Windows：Claude Code

1. 開啟檔案總管，在網址列輸入 `%USERPROFILE%`，按 Enter。
2. 若沒有 `.claude` 資料夾就建立；裡面再建立 `skills` 資料夾。
3. 把 `ntc-academic-kit\skills` 底下的九個資料夾複製進去。
4. 關閉並重新開啟 Claude Code。

用 PowerShell 的做法（在 ntc-academic-kit 資料夾內執行）：
```
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse -Path .\skills\* -Destination "$HOME\.claude\skills"
```

## Windows：Codex

1. 同上，在 `%USERPROFILE%` 建立 `.agents` 資料夾，裡面再建立 `skills`。
2. 把九個資料夾複製進 `%USERPROFILE%\.agents\skills`。
3. 關閉並重新開啟 Codex（或 ChatGPT 桌面 App 內的 Codex）。

```
New-Item -ItemType Directory -Force "$HOME\.agents\skills" | Out-Null
Copy-Item -Recurse -Path .\skills\* -Destination "$HOME\.agents\skills"
```

## macOS：Claude Code

在終端機，進入 ntc-academic-kit 資料夾後執行：
```
mkdir -p ~/.claude/skills
cp -R skills/* ~/.claude/skills/
```

## macOS：Codex

```
mkdir -p ~/.agents/skills
cp -R skills/* ~/.agents/skills/
```

## 如何確認安裝成功

1. 重新開啟工具後，對 AI 說：「請用 kit-guide 帶我開始」。若它開始問你身分與研究階段，就成功了。
2. Claude Code 直接問「你現在有哪些技能？」，看回答裡有沒有 kit-guide 等 9 支；Codex 可輸入 `/skills`，或用 `$kit-guide` 呼叫。（呼叫方式以工具官方文件為準。）
3. 找不到技能時，檢查：資料夾層級是否正確（應為 `skills\kit-guide\SKILL.md`，不是多包一層）、是否重新開啟過工具。

## 專題範本

把 `project-template` 裡的所有內容複製到你的專題資料夾。Claude Code 會讀 CLAUDE.md，Codex 會讀 AGENTS.md。
