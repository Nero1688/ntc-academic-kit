# 做一支專屬你自己研究的 skill

skill（技能）就是一份寫給 AI 助理看的作業流程說明，放在一個資料夾裡的 SKILL.md 檔案。你把自己固定要做的事（輸入什麼、怎麼做、做出什麼、怎樣算對）寫清楚，AI 助理之後遇到同類工作，就會照你的流程做。

兩個提醒先說在前面：

- **skill 是作業流程，不是槍手。** 它幫你把重複的步驟做得一致，但研究的判斷與寫作仍然是你的。
- **用別人的 skill 之前，先讀過它的 SKILL.md。** 看它要 AI 做什麼、會不會讀你的檔案、會不會上網，沒讀懂就不要裝。

## 第一步：寫下你的作業流程

不用寫得漂亮，先在紙上或文字檔寫下四件事：

1. **輸入**：你會給 AI 什麼？（例如 30 則民宿評論的文字檔）
2. **步驟**：你自己手動做的話，會依序做哪幾步？每一步用什麼規則？
3. **輸出**：你希望得到什麼？表格還是清單？有哪些欄位？
4. **怎樣算做對**：你怎麼檢查結果？（例如抽五筆回原文核對）

寫不出來，通常表示這件事你自己還沒做順，先手動做一次再回來寫。

## 第二步：請 agent 依範本產生 SKILL.md

把本資料夾的 SKILL.md（範本）當作骨架，連同第一步寫的內容一起交給 AI 助理（agent）。你也可以用官方的 skill-creator：

- **Claude Code**：可以先安裝官方 skill-creator。依序輸入
  `/plugin marketplace add anthropics/claude-plugins-official`
  `/plugin install skill-creator@claude-plugins-official`
  這兩行是在 Claude Code 的對話框裡輸入（和你平常打字問問題的地方一樣），不是在 PowerShell。裝好後問它「你現在有 skill-creator 嗎？」確認。
  （指令以官方文件為準，查證日 2026-11-09。）
- **Codex**：內建 skill-creator，不必另外安裝。

### 可照抄的提示範例

> 請依 skill-template 資料夾裡的 SKILL.md 範本，幫我做一支叫 minsu-review-coding 的技能。我的作業流程如下：輸入是一份民宿評論的 CSV；步驟是逐則讀評論，依我的編碼表（價格 P、服務 S、環境 E、交通 T）標記，一則可以有多個碼；輸出是一張表，欄位為評論編號、原文、編碼、判斷依據；檢查點是我會抽五則核對。請保留範本裡的六個段落與倫理防線，description 用中文並在 1024 字元以內。先給我看內容，我確認後再存檔。

## 第三步：用一個真實案例試跑

1. 把產生的資料夾放到技能目錄（見下方「放在哪裡」），重新開啟工具。
2. 找一個**真實但小量**的案例（例如 10 則評論），不要用含個人資料的檔案。
3. 對 AI 說：「請用 minsu-review-coding 處理這份檔案。」
4. 對照你第一步寫的「怎樣算做對」，逐條打勾。

## 第四步：看結果修一次

試跑後，把問題記下來，只修一次再試：

- AI 漏做了某步：把那一步寫得更具體。
- AI 做了你沒要求的事：在「步驟」或「檢查點」加一句「不要……」。
- 輸出格式不對：在「輸出格式」放一個完整範例。
- 該停下來問你卻沒問：在「檢查點」寫明什麼情況要先問。

修完再用另一批資料試一次。穩定之後再給同學用。

## 命名規則

- 技能名稱（name）只用小寫英文字母、數字與連字號，例如 minsu-review-coding。
- 名稱要和資料夾名稱完全相同。
- description 一定要寫，長度不超過 1024 字元；寫清楚「做什麼、何時用、觸發詞、不做什麼」。
- 檔名固定為 SKILL.md（大寫）。

## 放在哪裡

| 工具 | 個人技能目錄（所有專題都能用） |
|---|---|
| Claude Code | 家目錄的 `.claude\skills\你的技能名稱\SKILL.md` |
| Codex | 家目錄的 `.agents\skills\你的技能名稱\SKILL.md` |

Windows 的家目錄是 `C:\Users\你的帳號`。同一個技能想兩邊都用，就各放一份。放好後重新開啟工具。**不要**放進本工具包的 skills 資料夾，那是安裝腳本會複製的清單。

## 三個東專科系的 skill 點子

1. **民宿評論編碼規則**（餐旅管理科）：輸入是整理好的評論文字，依你定義的編碼表標記主題，輸出編碼表與判斷依據，並要求每筆都附原文。
2. **食品感官評價紀錄**（食品科技科）：輸入是評分員填的評分表（不含姓名），輸出各樣品各項目的平均與分布，並檢查是否有漏填；不下「哪個配方比較好」的結論，由你判斷。
3. **植栽調查表**（園藝暨景觀科）：輸入是現場記錄的植物名稱、位置與數量，輸出整理好的調查表，名稱與學名對不上時標「待查證」而不是自己補。

## 寫之前的自我檢查

- 這支技能會不會讓我少想一件我應該自己想的事？會的話，改成讓 AI 提問與檢查，不是代做。
- 我有沒有把含個資的檔案設計成要上傳？有的話，改成先去識別化。
- 倫理防線四條是否都還在？這一段不要刪。
