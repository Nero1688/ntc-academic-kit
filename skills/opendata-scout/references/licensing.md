# 授權與引用寫法

網址實測日 2026-11-09。授權條款會修正，引用前以官方最新頁為準。

## 一、政府資料開放授權條款第 1 版

官方全文：https://data.gov.tw/license （中華民國 104 年 7 月 27 日訂定）。要點如下，細節以全文為準。

| 項目 | 條款要點 |
|---|---|
| 授權範圍 | 不限目的、時間、地域，非專屬、不可撤回、免授權金；可重製、散布、公開傳輸、編輯、改作，也可做成衍生物 |
| 不包括 | 專利權與商標權 |
| 你的義務 | 以尊重第三人著作人格權的方式利用；依附件「顯名聲明」標示原資料提供機關；**沒有標示，視為自始未取得授權** |
| 與 CC 的關係 | 與創用 CC 姓名標示 4.0 國際版本相容（https://creativecommons.org/licenses/by/4.0/deed.zh-hant ） |
| 機關可停止提供 | 情事變更，或資料有侵害第三人權利之虞時，機關可停止提供，使用者不得請求賠償 |
| 免責 | 機關僅在知悉錯誤或遺漏時負修正責任；你利用資料造成的損害，由你自己承擔 |

白話：政府開放資料可以免費用在專題與報告，也可以改作，**但一定要寫出處**。

## 二、顯名聲明與引用寫法

條款附件要求的格式是：提供機關或單位、年份、開放資料釋出名稱與版本號，再註明依政府資料開放授權條款釋出，並附授權網址。

專題內文或圖表下方可以這樣寫（方括號請換成你的資料）：

> 資料來源：[提供機關]（[年份]）。[資料集名稱，含版本或資料期間]。依政府資料開放授權條款第1版釋出，https://data.gov.tw/license 。資料集頁面：[資料集網址]。下載日期：[年月日]。

參考文獻（APA 7 的政府資料集寫法，依指導老師或系上規定調整）：

> [提供機關]。（[年份]）。[資料集名稱]（[版本或資料期間]）[資料集]。[平臺名稱]。[資料集網址]

注意：

1. 年份、版本、更新日都要抄資料集頁面上的，頁面沒寫就寫「頁面未標示」，不要自己猜。
2. 資料集頁面的授權若不是政府資料開放授權條款，以該頁標示為準，並照它的要求引用。
3. 你自己整理、計算過的數字，要寫「依 [機關] [資料集名稱] 計算」，不要寫成機關公布的數字。
4. 引用的同時，把完整資訊記到資料來源紀錄（格式見 SKILL.md 第五步）。

## 三、不是所有政府網頁都是開放授權

- 開放授權通常指「資料集」。機關網站上的新聞稿、研究報告全文、照片與圖表，不一定適用，使用前看該頁或該站的使用說明。
- 資料集頁面沒有標示授權時，不要假設可以任意使用；改問指導老師，或寫信詢問提供機關。
- 學術調查資料（例如 SRDA，https://srda.sinica.edu.tw/ ）要註冊會員，並依各資料集與會員約定條款的規定使用，通常要求註明資料來源，也可能限制再散布。照條款做，不要把原始檔再轉給別人。

## 四、含個人資料的資料不要用

個人資料保護法（全國法規資料庫：https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=I0050021 ）管理個人資料的蒐集與利用。專題的做法：

1. 優先使用已彙總的統計資料（縣市、月份、品項層級），不用能辨識到個人的明細資料。
2. 打開資料就發現有姓名、電話、住址、身分證字號等欄位時，停止使用並告知指導老師，不要把原始檔貼給 AI。
3. 自己蒐集的問卷或訪談資料是另一回事，要依學校或指導老師的研究倫理規定辦理。

## 五、非政府資料：逐一看條款

民間網站、社群平臺、評論網站、電商網站的資料，授權與政府資料不同：

1. 找該站的「使用條款」「服務條款」，看有沒有禁止自動化存取、禁止重製或禁止用於研究。
2. 看網站的 robots.txt（網址通常是網站首頁加 /robots.txt），其中不允許的路徑不要用程式存取。
3. 條款禁止或看不懂時，不用，或改請使用者手動、少量取得並詢問指導老師。
4. 有官方 API 的平臺，只用 API，並遵守其速率限制與條款。
5. 條款也可能禁止把內容放進 AI 系統；不確定時，只提供自己整理的摘要，不貼原文。
6. Google Scholar 與華藝線上圖書館不可程式抓取，見 lit-search 的資料庫速查。

## 六、出處要自己核對

本檔整理自政府資料開放平臺公告的條款全文。條款、網址與平臺規定都可能更新；寫進作業或論文前，請使用者自己打開 https://data.gov.tw/license 與資料集頁面核對。
